# 견적 관리 모바일 — 3건 수정 지시문

**레포:** dlghdud64-art/BioInsight-Lab@main
**대상:** 견적 관리 모바일웹 (2026-07-31 실기기 스크린샷 3건 근거)

## 1. 견적 선택 시 뜨는 상세 바텀시트 — 삭제

증상: 리스트에서 견적 카드 탭 → "견적 요청 — N개 품목" 바텀시트(RFQ 번호·현재 단계 4항목·상태/차단/비교/전환 격자·차단 사유·보강 카드·`공급사에 전송 잠김` CTA)가 뜸.

지시: **이 바텀시트 표면 자체를 제거** (미사용 확정). 카드 탭 시 해당 견적의 기존 상세/작업 플로우로 직접 진입. 관련 컴포넌트·상태·핸들러까지 dead code 정리 — 표면만 숨기고 코드를 남기는 방식 금지. 시트 내 정보(차단 사유·보강 CTA)는 기존 카드/상세 화면이 이미 담당하므로 이전 불요.

## 2. 리마인더 발송 모달 — 기한 입력을 스테퍼로 교체

증상: `기한 [3]일` 자유 숫자 input에 포커스 시 iOS Safari가 화면을 자동 확대(폰트 16px 미만 input의 iOS 기본 동작) + 키보드가 모달을 가림.

지시: **자유 입력 제거 → 스테퍼로 교체.**
- UI: `[−] 3일 [+]` — 버튼 44px 히트 영역, 범위 1~14일, 경계에서 해당 버튼 disabled.
- 키보드 자체가 뜨지 않으므로 확대 문제 원천 제거.
- 프리셋 가속(선택): 스테퍼 위 `1일 · 3일 · 7일` 칩 3개, 탭 시 즉시 설정.

## 3. 전역 예방 — iOS 입력 자동 확대

지시: 전역 스타일에 아래 추가 (다른 화면의 소형 input 재발 방지):
```css
input, select, textarea { font-size: 16px; }
```
금지: viewport meta의 `maximum-scale=1`·`user-scalable=no` — 접근성(핀치줌) 차단이라 사용 불가.
