# 모바일 대시보드 개선 — 구현 지시문 (핸드오프)

**제품:** LabAxis · 메인 대시보드 모바일 웹 (`/dashboard`, viewport < 768px)
**범위:** 재고 경고 카드 톤 다운 · 다음 단계 추천 배너 확대 + 고도화 6종
**프로토타입:** `모바일 대시보드 개선.dc.html` (1a 기본 수정안 / 2a 고도화안)

---

## 1. 기본 수정 (1a)

### 재고 경고 카드
- **배경 채색 제거** — 연분홍 배경+분홍 보더 → **흰 카드 + 기본 보더** `#e6eaf0`.
- 레드는 포인트만: 아이콘 칩 `#fef2f2/#b91c1c`(22px 라운드 사각), 타이틀·숫자 `#b91c1c`.
- 서브텍스트(안전재고 미달)는 중립 그레이 `#94a3b8`.

### 다음 단계 추천 배너
- 한 줄 말줄임(…) 제거 → **2줄 구조**: 상단 라벨 `다음 단계 추천`(11px, `#93c5fd`) + 본문 전문(13.5px, line-height 1.5, `text-wrap:pretty`).
- 배너 높이는 내용에 따라 자동 확장. 아이콘 칩 38px + 우측 `›` 원형 버튼 34px + `✕`.
- 배경: `linear-gradient(135deg,#16233f,#1d3157)`, radius 16.

## 2. 고도화 (2a) — 6종

1. **오늘 할 일 = 실행 큐** — 유형별 행(재고 부족/회신 도착/입고 예정), 각 행 = 아이콘 칩(앰버/블루/그린) + 제목·부제 + 건별 CTA(1차 파랑, 나머지 아웃라인). 헤더에 `전체 보기 ›`.
2. **지출+예산 통합 카드** — ₩0 + 전월 대비 + **미니 스파크라인**(최근 추이, 마지막 점 파랑) + 하단 인라인 바 `예산 미설정 · 지출만 기록 중 / 예산 설정 ›`. **별도 예산 힌트 카드 삭제.**
3. **역할 분리** — 재고 경고 카드는 순수 카운트 + `처리 ›` 딥링크(오늘 할 일의 재고 처리와 동일 목적지). 중복 서사 제거.
4. **온보딩 스텝** — 배너 라벨에 `· 1/3`, 하단에 진행 점(활성 18px 바 + 비활성 점) + 단계 텍스트 `예산 등록 → 견적 첫 발송 → 재고 등록`. 단계 완료 시 다음 추천으로 로테이션.
5. **운영 브리핑 FAB** — 기본은 라벨 있는 pill(✦ 운영 브리핑, 하단 내비 바로 위). 스크롤 다운 시에만 46px 원형(✦)으로 축소, 최상단/정지 시 pill 복원. **콘텐츠 터치 타겟(특히 재고 경고 `처리 ›`)을 어떤 상태에서도 가리지 않게** 콘텐츠 하단에 FAB 높이만큼 여백(≈88px) 확보.
6. **내비 뱃지** — 재고 탭 아이콘 우상단 레드 뱃지(경고 건수). `min-width 15px`, 9.5px 볼드.

## 4. 상호작용 규칙

- 실행 큐 행 CTA는 해당 플로우 딥링크(재고 처리/선택안 검토/입고 반영). 완료 시 행 체크오프 후 큐에서 제거.
- 재고 경고 `처리 ›` = 실행 큐 재고 행과 동일 목적지.
- 배너 `✕` = 현재 추천만 dismiss(다음 단계 추천으로 교체), 3단계 완료 시 배너 숨김.
- FAB: 스크롤 다운 시 축소, 최상단에서 pill 확장. 어떤 상태에서도 콘텐츠 터치 타겟을 가리지 않을 것.
- 터치 타겟 최소 44px.

## 5. QA 체크리스트

- [ ] 재고 경고 카드에 배경 채색 없음(흰 카드 + 레드 포인트만)
- [ ] 추천 배너 문구가 말줄임 없이 전문 노출
- [ ] 오늘 할 일이 3건 큐로, 행별 CTA 동작
- [ ] 예산 힌트 카드가 사라지고 지출 카드에 통합
- [ ] 배너에 1/3 진행 점 + 단계 텍스트
- [ ] FAB이 재고 경고 `처리 ›` 등 콘텐츠를 가리지 않음
- [ ] 재고 탭 뱃지 = 경고 건수
- [ ] 터치 타겟 44px 이상
