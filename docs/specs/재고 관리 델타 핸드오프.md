## 1. 우측 레일(품목 브리핑) — 델타 3건

현재 레일 골격(상태 카드·리스크·연결된 흐름·LOT 접기)은 유지. 아래만 수정:

1. **AI 재발주 섹션 고도화** — `재발주 우선순위 · 권장 9개`를 고도화 버전으로 교체:
   - 소진 추이(최근 8주 막대 + 예측 막대 빗금 + 소진 예상일). 데이터 2주 미만이면 그래프 숨기고 텍스트만.
   - 권장 수량 = `안전재고 갭 + 납기 중 소진(리드타임 × 주당 소진) → 최소 주문 단위 반올림` — 근거 항목별 노출.
   - 공급사: 구매 이력 기반 후보(이력 배지·단가·납기) + `다른 공급사 ›`. 미지정이면 선택이 관문.
   - CTA `견적 초안 만들기 · N개 ›` — 서버 생성 확인 후 견적 관리 딥링크(front-only success 금지).
   - **웹·모바일 동일 소스** — 모바일 바텀 시트와 같은 API·같은 숫자.
2. **액션 단일화** — 상단 `재주문` 버튼 제거(AI 섹션 CTA와 중복). 상단은 `정보 수정`만.
3. **표시 버그**
   - `만료 임박 D-1425` — D-day는 **≤90일에만** 노출. 그 외엔 날짜만.
   - COA `불러오는 중...` 무한 스피너 — 로딩 실패 시 에러 + 재시도로 전환(실패 삼킴 금지).
   - 최근 구매의 `공급사 미지정`은 리스크 섹션에도 승격(재발주 관문과 연결).

## 2. 라벨 인쇄 (1a·1b)

### 시트 그리드 정착 (버그)
- 현행: 출력물이 규격 그리드와 무관하게 **세로 1열**로 인쇄 → 실물 라벨지와 어긋남.
- 수정: 칸 좌표를 **mm 절대 배치**(`@page` 여백 0, 폼텍 3100 = 38.1×21.2mm, 5열×13행, 칸 간격 포함). 어떤 칸에서 시작해도 물리 라벨지와 1:1.

### 시작 칸 선택
- 모달에 미니 시트(5×13) — **칸 탭 = 시작 위치**. 사용된 칸은 빗금(로컬 기억), 이번 인쇄분은 파랑 하이라이트.
- 푸터에 `N개 품목 × M장 · 6~8번 칸 · 잔여 57칸`.

### 라벨 내용
- EXP는 `YYYY.MM.DD` 포맷 — 원시 ISO 문자열(`2030-06-16T00:00:00.000Z`) 인쇄 금지.
- 규격별 레이아웃 프리셋: 3100(소형)=QR+품명·LOT·EXP 3줄만, 3104(대형)=QR+1D+EXP. 긴 원시 ID 문자열은 QR에만 수록.
- 미리보기는 규격 **실비율**, 규격 변경 시 갱신. 커스텀 규격 선택 시 치수 입력 인라인 노출(dead option 금지).

## 3. KPI 카드 클릭 배선 (1c)

- **카운트 있는 KPI 카드 = 클릭 → 리스트 필터 토글.** 선택 시 파란 보더 + `필터 중 ✕`, 리스트 위 활성 필터 칩.
- 0건·정상 카드는 비클릭(커서 default).
- **격리 Lot 카드 제거**(격리는 범위 제외 확정).
- 노란 운영 배너는 조치 **2건+ 복합 상황에만** — 단건이면 KPI 카드가 그 역할(중복 신호 금지).

## 5. QA 체크리스트

- [ ] 레일 권장 수량 = 상태 카드 CTA 수량 = 모바일 시트 수량 (단일 소스)
- [ ] 근거 분해(갭+납기 소진+반올림) 표시, 데이터 부족 시 그래프 폴백
- [ ] 상단 `재주문` 버튼 제거, CTA 1개
- [ ] D-day ≤90일에만 · COA 실패 시 재시도
- [ ] 라벨 출력이 실물 라벨지 칸과 1:1 정착 (시작 칸 포함)
- [ ] 시작 칸 탭 선택 · 사용된 칸 기억 · 잔여 칸 표시
- [ ] EXP 포맷 · 규격별 프리셋 · 실비율 미리보기
- [ ] KPI 카운트 카드 클릭 = 필터 토글, 0건 비클릭
- [ ] 격리 Lot 카드 없음 · 배너는 2건+만
