# 견적 공급사 추가·발송 모달 (모바일) — 검토 결과 및 수정 지시문

**레포:** dlghdud64-art/BioInsight-Lab@main
**근거:** 2026-07-31 실기기 스크린샷 3건 (공급사 추가 모달 · 발송 검토 상단 · 발송 검토 하단)

## 1. 공급사 추가 모달 — 실패 안내 가독성 (요청 건)

현재: yellow 점선 카드 `공급사 후보 선별 실패` + 본문 2문단("해당 품목에 매칭되는… DB에 연락 채널이 등록되지 않았습니다." / "위 **"이메일 직접 입력"**으로…") — 제목 대비 본문이 길고, 인용부호+볼드 혼용, 줄바꿈이 어중간.

수정:
- **위치 이동** — 경고가 참조하는 "이메일 직접 입력"보다 **위**에 배치 (원인 → 해결 순서). "위 …으로" 같은 위치 지시어 제거.
- **문구 1~2줄로 축약** (기술 어투 제거):
  - 제목: `매칭되는 공급사가 없습니다` (‘선별 실패’ 금지 — 시스템 오류처럼 읽힘)
  - 본문: `아래에서 이메일로 공급사를 직접 추가하면 바로 발송할 수 있습니다.` 한 줄.
- 타이포: 제목 14px/700, 본문 13px/400, 행간 1.6, 인용부호·볼드 혼용 제거. 점선 보더 → 실선(#fde68a) 통일.

## 2. 공급사 추가 모달 — 빈 섹션 정리

`등록된 공급사 0건` + `LabAxis 추천 0건` 두 빈 섹션이 상단 절반을 차지. 0건일 때는 **한 줄로 접기**(`등록·추천 공급사 없음`) 또는 숨기고, §1 안내 + 이메일 입력이 첫 화면에 오게.

## 3. 발송 검토 모달 — 같은 경고 3중 노출 정리

현재 "공급사 없음"이 3곳에서 반복: ① 헤더 부제 ② 파란 안내 카드 ③ 하단 red `연락처 필요` 박스.

수정:
- 헤더 부제는 중립으로: `수신 공급사와 메시지를 확인한 뒤 전송합니다.`
- **파란 안내 카드 1곳만 유지** (스텝퍼 바로 아래, 해결 CTA 포함).
- red `연락처 필요` 박스 삭제 → 전송 버튼 disabled + 바로 위 한 줄 사유(`공급사 추가 후 전송 가능 · 0곳` — 이미 있음)로 충분.

## 4. 응답 요청 기한 — 스테퍼 교체

`[14] 일 (1~90)` 자유 입력 → iOS 포커스 자동 확대 동일 문제. `[−] 14일 [+]` 스테퍼(1~90, 길게 누르면 가속) + 프리셋 칩 `7 · 14 · 30일`. (리마인더 모달 스테퍼와 같은 컴포넌트 재사용 — `견적 모바일 수정 3건.md` §2와 짝.)

## 5. 하단 버튼 위계

현재: `취소`(전폭) → `견적요청서 다운로드`(전폭) → `선택 공급사에 요청 전달`(전폭 disabled) — 취소가 가장 먼저·같은 크기로 노출돼 위계 역전.

수정 (데스크톱 확정안과 동일 문법):
- 최하단 sticky: **`선택 공급사에 요청 전달`** primary 전폭 (disabled 시 사유 문구 유지)
- 그 위 보조: `견적요청서 다운로드 · 직접 전달용` outline
- `취소`는 전폭 버튼 제거 — 헤더 ✕와 시트 드래그 닫기로 충분. 유지해야 하면 최하단 텍스트 버튼.

## 발송 검토 모달 — 잘 된 부분 (유지)

4단계 스텝퍼(현재 단계 amber 경고 아이콘) · 파란 안내의 해결 지향 문구 · `이메일로 공급사 추가` 히어로 + `LabAxis 추천 공급사 탐색` 대안 · 케이스 칩(RFQ 번호·품목 수).
