## 1. 상태 액션 카드 통합 (최우선)

현재: 빨간 카드에 점 + "안전재고 미달 / 안전재고 보충 권장" 텍스트만, CTA는 아래 "재발주 우선순위" 별도 섹션.
수정: 하나의 상태 액션 카드로 통합 —
- 아이콘 + `안전재고 미달` 타이틀 + **부족 수량 명시** ("현재 1개 · 안전재고 10 대비 9 부족")
- **현재/안전 갭 게이지** (1/10, 레드)
- 카드 내 CTA `재발주안 검토 · 권장 9개`
- 상태별 자동 전환: 부족=레드 / 만료 임박=앰버 / 정상=그린("재고 상태 양호")
- 기존 "재발주 우선순위" 섹션의 권장 수량 근거(+9 갭·납기 소진·주문 단위)는 카드 아래 접힌 근거 행으로 흡수. 섹션 중복 제거.

## 2. 라벨 오류 수정

- `만료 임박: 2030.06.16` → 라벨 `최단 유효기간` + D-day 배지 (≤30 레드 / ≤90 앰버 / 그 외 배지 없음). 4년 남은 날짜에 '임박' 표기 금지.
- 재고 현황 게이지에 수치 병기 (`1 / 10`) — 바만 단독 금지.

## 3. 액션 버튼 행

`정보 수정` 단독 → `입·출고 기록` / `정보 수정` 2버튼 나란히 (flex gap-2).

**`입·출고 기록` 목적지 — 신규 "시약 이력 추적" 화면으로 딥링크** (별도 기록 화면 신설 금지 — 중복 표면):
- 라우팅: `/dashboard/inventory/history?itemId={id}` — 품목 프리셀렉트 + 기간 전체 기본값으로 진입.
- 이력 추적 화면 미구현 단계에서는 버튼 미생성(disabled 아님) — dead button 금지. 구현 후 배선.
- 브리핑 내 `최근 입출고`(§4-7) 미니 타임라인은 최근 3~5건 요약만 + 하단 `전체 이력 보기 ›` 링크로 같은 곳 딥링크 — 역할 분리: 브리핑 = 요약, 이력 추적 = 전수·출력.

## 4. 누락 섹션 4개 추가 (§3 순서대로)

5. **운영 리스크** — 현행 유지 (공급사 미지정·위치 미지정). 단, 상단 "공급사 후보 없음" 회색 텍스트와 중복 — 리스크 섹션으로 일원화하고 상단 텍스트 제거.
6. **연결된 흐름** — 최근 구매 · 입고 예정 (있을 때만).
7. **최근 입출고** — 입고/출고/이동 타임라인, 색 마커.
8. **권장 액션 · 추천 이유** — 정기 점검 등 + 실행 버튼.
9. **최근 수정 이력** — 마지막 수정 · 수정자 · 변경 내용.

## 5. 유지 (잘 된 부분)

권장 수량 근거 분해 · LOT 카드 + COA 업로드 · 리스크 2건 구조.
