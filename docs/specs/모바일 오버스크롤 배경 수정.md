# 모바일웹 오버스크롤 흰색 배경 — 수정 지시문

**레포:** dlghdud64-art/BioInsight-Lab@main
**증상:** 모바일웹(iOS Safari) 대시보드에서 끝까지 스크롤 후 더 당기면(고무줄 바운스) 페이지 밖 영역이 **흰색**으로 드러나 페이지 배경(slate)과 갈라져 보임. (2026-07-31 실기기 스크린샷 확인)

## 원인

레이아웃 버그 아님 — iOS 오버스크롤은 정상 동작. 페이지 배경색이 콘텐츠 래퍼 div에만 선언돼 있어, 오버스크롤로 드러나는 html/body 영역이 브라우저 기본 흰색.

## 수정 (1건)

```css
html, body { background: #f8fafc; } /* 페이지 배경을 최상위로 승격 — 기존 래퍼 배경 토큰과 동일 값 사용 */
```

- Tailwind면 `globals.css`의 `@layer base`에 추가하거나 `<html className="bg-slate-50">`.
- 기존 콘텐츠 래퍼의 배경 선언은 유지(중복 무해).

## 하지 말 것

- `overscroll-behavior-y: none` 금지 — 바운스는 없어지지만 당겨서 새로고침도 막힘. 색 통일만.
- 콘텐츠 래퍼에 `min-h-screen`·`padding-bottom` 추가로 여백을 메우는 방식 금지 — 오버스크롤은 레이아웃 밖 영역이라 효과 없고 dead space만 생김.
