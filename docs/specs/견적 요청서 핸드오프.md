## 1. 문서 구조 (A4 세로, 위→아래)

1. **레터헤드** — 좌: `LabAxis` 워드마크(블루) + `견 적 요 청 서` 대제 / 우: 문서정보 표 — 문서번호(RFQ, mono)·발행일·**회신 기한(레드 강조, 발송 모달 응답 기한으로 계산)**. 하단 2.5px 다크 룰.
2. **수신/발신 2단 표** — 수신: 공급사명 귀중 + 담당 부서. 발신: 기관명 + `담당 {실명} · 전화`. 공급사 미지정 다운로드 시 수신은 빈칸(`(수신처 기재)`) — "(공급사 미지정)" 같은 시스템 문구 금지.
3. **인사 문단** — "귀사 견적서 양식으로 회신 기한 내 회신 부탁드리며, 단가·납기·최소 주문 수량·견적 유효기간을 포함해 주세요."
4. **품목 표** — 다크 헤더(#0f172a/흰 글자): `No | 품목명/제조사·카탈로그 번호 | 규격 | 수량 | 요청 사항`. 요청 사항 셀: `단가·납기·최소 주문 수량` (word-break:keep-all). 공급사 기재란 없음 — 공급사는 자사 양식으로 회신.
5. **각주** — `※ 견적 금액은 부가세 포함 여부를 명기해 주세요.`
6. **조건 표** — 회신 방법 / 요청 조건 / 비고 3행.
7. **결문** — "위와 같이 견적을 요청합니다." + 기관명 + `담당 {실명}` 가운데 정렬. **(인)·서명란 없음.**
8. **푸터** — 자동 생성 고지 + labaxis.co.kr + 문서번호.

## 2. 회신 매칭 (핵심 배선)

- 회신 방법: **`{RFQ번호}@reply.labaxis.co.kr`** 케이스별 회신 주소 (표기는 대문자 `RFQ-2606-8EBG@…`).
- 서버 수신 매칭은 로컬파트 **case-insensitive** — 공급사가 소문자로 보내도 매칭.
- 매칭 시: 해당 RFQ 회신 타임라인 자동 기록 + 상태 `회신 대기 → 회신 수신` 전환 + 첨부는 케이스 문서함. 발신 공급사 식별은 보낸 도메인.
- 금액·납기 **자동 기입은 1단계 제외** — 담당자 확인 입력. (2단계: 파싱 제안 → 확인 후 반영. front-only 자동 기입 금지.)

## 3. 데이터 규칙

- 담당자 = 사용자 프로필 **실명** 필드. 미입력 시 다운로드 전 입력 유도 — 계정 ID(young a 등) 대체 금지.
- 회신 기한 = 발송 모달 응답 요청 기한(일)로 발행일 + N일 계산, `YYYY. MM. DD. (N일)` 표기.
- 규격 없으면 `—`. 예상 금액(₩0) 노출 금지 — 현행 문서의 "예상 금액: ₩0" 삭제.
- 문구 금지어: 동등품/대체품(옵션으로 요청자가 비고에 직접 기재할 때만), '회신 요망', 시스템 어투("(공급사 미지정)").
