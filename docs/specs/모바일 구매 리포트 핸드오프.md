# 모바일 구매 리포트 개선 — 구현 지시문 (핸드오프)

**제품:** LabAxis · 구매 리포트 모바일 웹 (`/dashboard/reports`, viewport < 768px)
**범위:** 헤더·기간/필터 · KPI 카드 · 빈 상태 · 상세 분석(빈/데이터 2상태)
**프로토타입:** `모바일 대시보드 개선.dc.html` — 6a(화면) · 6c(상세 분석 데이터 상태)

---

## 0. 원칙

- **지출은 가져오지 않는다.** LabAxis 발주 완료 건이 **자동 집계**되는 것이 유일한 데이터 소스. 업로드/가져오기 UI 금지.
- **탭 분리 금지.** `기간/필터 → KPI → 상세 분석` 단일 세로 스크롤. 깊은 분석은 딥링크로 이동(요약 카드 + 상세 페이지 2단 구조).

## 1. 헤더 · 기간 · 필터 (6a)

- 상단 액션: 다운로드 아이콘 1개만(타이틀 행 우측). 가져오기 버튼 제거, 새로고침은 당겨서 새로고침으로.
- **날짜에 모노 숫자 금지** — `2026.07.13 – 2026.07.20` → 본문 폰트 `7월 13일 – 7월 20일`(올해면 연도 생략).
- 기간 프리셋(7일/30일/분기/올해 세그먼트 풀폭) + 날짜 + 필터를 **카드 하나로 묶음**. 필터 버튼에 적용 개수 배지.

## 2. KPI 카드

- 여백만 큰 세로 1열 카드 금지 → **2열 컴팩트 그리드 4장**: 지출 변화(%) · 이상치 감지(건) · 기간 합계(원) · 공급사 의존도(상위 1곳 %).
- 카드 구조: 아이콘 칩 26px + 우측 보조 라벨 → 숫자 22px + 단위 → 설명 한 줄.
- 값 없음은 `–` 표시(0과 구분).

## 3. 빈 기간 상태

- KPI 전부 0 나열 대신 점선 카드: "이 기간에 집계된 지출이 없어요 / **발주가 완료되면 지출이 자동으로 집계됩니다**" + CTA `기간을 30일로 넓히기`.

## 4. 상세 분석 — 같은 슬롯, 상태 전환

**빈 상태(6a):** 거대한 "데이터 없음" 박스 금지. 카드 1장에 접힌 행 3개(아이콘+제목+안내 한 줄), 우측 링크는 회색 비활성.
- 카테고리별 분석 · "집계된 지출이 생기면 표시돼요"
- 공급사 의존도 · "발주 공급사 비중을 분석해요"
- 월별 지출 추이 · "2개월 이상 쌓이면 추이가 그려져요"

**데이터 상태(6c):** 각 행이 **제자리에서 미니 차트 카드로 확장**(위치·순서 불변). 섹션별 혼합 허용(있는 것만 확장). 차트는 라이브러리 없이 CSS/inline SVG.
1. **카테고리별 분석** — 상위 3개 가로 막대, 금액·비중 병기(`₩1,120,000 · 61%`), 링크 `카테고리 검토 ›` 활성.
2. **공급사 의존도** — 스택 바 + 범례(상위 2곳 + 기타). **상위 1곳 60% 초과 시 warm warning 배너**: "대체 공급사 검토를 권장해요". KPI 의존도 숫자와 동일 소스.
3. **월별 지출 추이** — 헤더 아래 **당월 값 한 줄**(`182만원 +18% · 7월`), 막대 3개월(당월 파랑 강조, **막대 위 숫자 금지** — 링크와 겹침), 하단 한 줄 해석("배지·시약 발주 증가 영향"). 최소 2개월 데이터부터 렌더.

## 5. 스타일 토큰

| 항목 | 값 |
|---|---|
| 폰트 | Pretendard 단일(숫자·날짜 포함, mono 금지) |
| 카드 | 흰 배경 · 보더 `#e6eaf0` · radius 14–16 |
| 세그먼트 | track `#f1f5f9`, 선택 흰 배경 + shadow |
| 차트 주색 | `#2563eb`(당월/1위), 보조 `#60a5fa/#bfdbfe`, 과거 `#cbd5e1/#e2e8f0` |
| 의존도 | `#6d28d9/#a78bfa/#ddd6fe` |
| 경고 배너 | warm warning — **yellow 토큰**(`bg-yellow-50/text-yellow-700`, amber sentinel 준수) |
| 증가/감소 | 증가 `#dc2626` · 감소 `#059669` |

## 6. QA 체크리스트

- [ ] 가져오기/업로드 UI가 없다 (발주 자동 집계만)
- [ ] 날짜가 본문 폰트 한국어 표기
- [ ] 프리셋·날짜·필터가 한 카드, 필터에 개수 배지
- [ ] KPI 2열 4장, 값 없음은 `–`
- [ ] 빈 기간 = 점선 카드 + 자동 집계 안내
- [ ] 상세 분석: 빈 상태 접힌 행 / 데이터 시 제자리 확장, 탭 없음
- [ ] 의존도 60% 초과 경고 배너(yellow 토큰)
- [ ] 월별 추이: 막대 위 숫자 없음, 당월 값 헤더 통합
- [ ] 차트 라이브러리 미사용(CSS/inline SVG)
- [ ] 터치 타겟 44px 이상
