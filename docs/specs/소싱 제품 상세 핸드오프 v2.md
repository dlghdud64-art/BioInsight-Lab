## 0. 현행 문제 (2026-08-09 실기기·배포본 확인)

1. **buyer에게 편집 권한 UI 노출** — 스펙 편집 ×3, 안전 정보 편집, SDS 업로드 ×2, 정보 요청 링크가 buyer 화면에 렌더. canEditSpec = ADMIN/SUPPLIER인데 링크는 전원 노출 → dead link 6개.
2. **완성도 25% 게이지 카드** — buyer가 행동 불가한 내부 데이터 품질 정보가 화면 상단 점유.
3. **모바일 줄바꿈 불안정** — "안전 · 규제 / 정보" 3단 줄바꿈, 위험도 칩 이탈, 메타 4열 flex 붕괴.
4. **포털 6기관 세로 나열** — 아코디언 안에 링크 6개 나열, 스캔 불가.
5. **대체품 카드 3장 = 1.5화면** — 카드당 반화면 + "유사한 스펙" 칩 중복 + 근거 없음.
6. **"구매 의무가 없습니다" 상시 문구, 견적 담기 후 toast no-op**, 내부 용어 메타(출처: 대장, 내부 등급).

## 1. 권한 규칙 (전 표면 공통)

- 스펙 편집·안전 정보 편집·SDS 업로드는 **buyer에게 버튼 미생성** (disabled 아님). ADMIN/SUPPLIER만 렌더.
- SDS/제품 정보는 **공급사/관리자만 등록** — 개인 업로드 금지(오매칭 위험, canonical 소스 단일 관리).
- buyer에겐 `등록 없음 · 공급사/관리자 등록 시 표시` 정직 표기만.
- 완성도 게이지 삭제 → 접힌 1줄 `일부 정보 미등록 · 견적·문의 시 안내됩니다` (탭 시 미등록 목록). 완성도 관리는 공급사 콘솔 몫.

## 2. 제품 카드 (2a 모바일 / 2d 웹 헤더)

- 메타에서 **내부 등급·출처(대장) 삭제**, 안전 위험도는 안전·규제 카드에만(이중 표기 제거). 분류는 칩 1개.
- 모바일 메타는 고정 그리드(flex 줄바꿈 금지).
- Cat.No·코드류 = IBM Plex Mono 500/600 (폰트 로드 필수), 전역 tabular-nums.

## 3. 우리 조직 거래 맥락 (신규 가치 블록 — 배선 트랙)

헤더 카드 안 3열 그리드:
- **우리 조직 재고**: `2개 보유 · 안전재고 미달` (미달 red #b91c1c) — 재고 모듈 연동, 중복 구매 방지.
- **최근 구매**: `2026. 5. 12. 수량 3개` — 발주 모듈 연동. 날짜와 수량은 구분 표기(가운뎃점 나열 금지).
- **구매가 이력**: `₩45,000 · 최근 2회 평균 ₩46,500` — 가격 판단 근거.
- 데이터 없으면 블록 자체 숨김(대시/빈칸 금지).

## 4. 재발주 맥락 배너 (신규 — 소싱↔재고 연결)

재고관리에 해당 품목의 재발주안(검토 중)이 존재하면 헤더 아래 블루 배너:
`재고관리에서 재발주 검토 중인 품목입니다 · 권장 N개` + **`재발주안에 합류`** CTA → 기존 재발주안에 이 품목/공급사 후보로 합류(새 견적 중복 생성 방지). 재발주→견적 핸드오프 트랙(§재발주 견적 핸드오프)과 동일 파이프라인.

## 5. 안전·규제 정보 (2b·2d)

- 헤더 1행 고정: 방패 라인 아이콘 + 제목(nowrap) + `위험도 미분류` pill(nowrap, flex:none).
- SDS 행: 상태 1행 — `등록 없음 · 공급사/관리자 등록 시 표시됩니다`. 요청/업로드 버튼 없음(buyer).
- 포털: **주요 2기관 버튼**(식약처·화학물질안전원, 외부 링크 아이콘) + `더보기 4개 기관 ›` 텍스트.
- 경고문은 회색 각주 1줄(yellow 박스 과경고 제거): "참고용 정보입니다. 취급/보관/폐기 지침은 SDS/MSDS 원문을 우선 확인하세요."

## 6. 대체품 추천 (2c·2d)

- 대형 카드 → 컴팩트 행(모바일 세로 스택 / 웹 3열). 품목명 + Cat mono + `상세 ›`.
- **매칭 근거 칩 1개 필수**: `같은 분류 · 규격 일치` / `용도 유사` / `구매 이력 있음` — 근거 산출 불가 품목은 추천 미노출.
- 비교 버튼은 비교 화면 배선 전까지 미생성(dead button 금지).

## 7. 견적 바 (전 표면)

- 1행 압축: `견적가 안내 품목` + `견적 담기`. "구매 의무가 없습니다"·납기 상시 문구 삭제 — 첫 담기 시 1회 안내(toast/시트)로.
- 담기 후 **버튼 상태 전환**: `담김 ✓ · 견적함 보기` (현행 toast만 뜨는 no-op 수정 — grid-cols-2 빈 반쪽도 제거).
