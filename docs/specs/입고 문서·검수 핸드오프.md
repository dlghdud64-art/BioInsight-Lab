# 입고 문서 첨부 · 검수 — 구현 지시문 (핸드오프)

**레포:** dlghdud64-art/BioInsight-Lab@main
**대상:** 입고 관리 — 문서 첨부 모달 + 입고 검수 (웹 · 모바일웹 · 앱)
**시각 truth:** `입고 문서·검수 개선 (단독).html` — 2a 웹 검수 · 2b 모바일/앱 검수 · 1a 문서 첨부

## 0. 현행 버그 (release blocker)

1. **문서 첨부 "추가" = front-only success** — 파일 선택기 없이 클릭 즉시 완료 처리. 업로드 배선 없음.
2. **MSDS 허위 표시** — 첨부 이력 없는데 첨부됨 렌더 (mock 하드코딩).
3. **검수 화면 전체가 정적 표시물** — 라인·"검수 합격" 배지만 있고 판정 입력·수량 확인·불합격 처리 액션 0.

## 1. 문서 첨부 모달 (1a)

- **추가 = 파일 선택기 오픈** → 업로드 진행률 바(취소 가능) → **서버 확인 후에만** `첨부됨` 상태. 즉시 완료 금지.
- 상태는 문서 레코드에서만 파생 — 하드코딩 금지. 표기: 1줄차 파일명·용량, 2줄차 `YYYY. M. D. {실명} 첨부` (날짜 형식 통일).
- 슬롯: 거래명세서(첨부됨: 보기/삭제) · COA(업로드 중: 진행률+취소) · 기타 드래그앤드롭 존.
- **MSDS = 품목 단위 문서** — 품목에 등록돼 있으면 `품목에 등록됨` 자동 연동 카드(보기/교체, 등록일 표기), 매 입고 재첨부 불필요. 미등록 품목만 업로드 슬롯 노출.
- 푸터 카운트: `첨부 N · 업로드 중 N · 품목 연동 N`.

## 2. 검수 — 데스크톱 웹 (2a)

- 6열 표: 품목(제조사·Cat) | Lot/유효기간 | 발주 | 수령(입력) | 상태(파생) | 판정(버튼).
- 헤더에 진행률 바 + `N/M 판정`.
- **판정 완료 행** — 그린 배경, 상태 pill `합격`, 버튼은 `판정 취소`만.
- **수량 불일치** — 수령 입력이 발주와 다르면 상태 `불일치 −N`(레드), 하단 불일치 패널 활성: 처리 경로 3택(부족분 재배송 요청 / 부분 입고로 확정 / 반품) + 사유 메모 **필수**.
- 첨부: 상태 사진(파손·라벨)·문서(COA·명세서 — MSDS 제외) 카운트 표기.
- 푸터: `임시 저장`(중간 이탈 안전) + `검수 완료 — 재고 반영`. **전 품목 판정 + 불일치 사유 입력 전 disabled + 남은 일 텍스트 표기** (사유 없는 비활성 금지).

## 3. 검수 — 모바일웹 · 앱 공용 (2b)

- 품목별 **카드 스택**. 판정 완료 카드 = 그린 보더 접힌 요약(발주/수령 + 판정 취소).
- 미판정 카드 = 수량 **스테퍼(− N ＋)** — 키보드 미노출 → iOS 자동 줌 원천 차단. 합격/불합격 풀폭 버튼, 불일치 처리(3택 칩 + 사유)는 카드 내부 인라인.
- 상단 진행률 바 + `N/M 판정` pill, 하단 **sticky CTA** `검수 완료 — 재고 반영` + 남은 일.
- **앱(RN)**: 동일 구조 + 카메라(사진 첨부)·**바코드/QR Lot 스캔**만 네이티브 추가. 오프라인 시 판정 mutation queue 적재 후 sync.

## 4. Lot · COA 자동 인식

- COA 업로드 시 Lot 번호·유효기간 **OCR/파싱 자동 인식** → 필드에 파란 배경 + `COA 인식` 배지로 채움.
- **자동 기입만으로 확정 금지** — 담당자 확인·수정 후 판정 시 확정 (front-only 자동 확정 금지).
- Lot 미입력 합격 = 수량 모드 반영 + "Lot 추적 불가" 안내 1줄.

## 5. 재고 연동 (핵심 배선)

검수 완료(합격) 확정 시:
- 품목별 **Lot 레코드가 재고관리에 자동 생성** — 수량·유효기간·COA 링크 이관.
- 보관 위치 미지정 시 재고관리 운영 리스크 표시로 연결.
- 품목 브리핑 LOT 카드에 즉시 노출, 입고 이력 타임라인 기록.
- 부분 입고 확정 시 잔여분은 입고 예정으로 유지(재배송 추적).
- 입고 모달 '입고 출처 = 발주 건 연결'과 동일 파이프라인 — 검수 합격분만 재고 반영, 이중 반영 금지.
