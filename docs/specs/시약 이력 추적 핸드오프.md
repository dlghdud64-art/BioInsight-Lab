# 시약 이력 추적 — 신규 화면 구현 지시문 (핸드오프)

**레포:** dlghdud64-art/BioInsight-Lab@main
**신규 라우트:** `/dashboard/inventory/history?itemId={id}&lot={lotNo}&from=&to=`
**시각 truth:** `시약 이력 추적.dc.html` (1a 데스크톱 · 1b 모바일+상태 4종 · 1c PDF · 2a 모션 데모)
**진입:** 재고 품목 브리핑 `입·출고 기록` 버튼 딥링크 (품목 프리셀렉트) — 별도 최상위 메뉴 아님. `품목 브리핑 보완 핸드오프.md` §3와 짝.

## 0. 목적

1차: 실사 대응 — 특정 시약의 입고→사용→회수 전 이력을 한 화면에서 확인하고 제출용 리포트로 출력. 2차: 사용량 파악. **탐색이 아니라 출력·증빙이 우선** — same-canvas에서 필터·조회·출력 완결.

## 1. 화면 구성 (1a 데스크톱)

1. **요약 헤더** — 품목명 + `Lot 추적` 배지(모드별: 수량 추적/Lot 추적 — **GMP 배지 없음**) + Cat·CAS·제조사 / 우측 `Excel` + `실사 리포트 PDF`(primary, #0f172a).
2. **요약 4지표** — 현재 재고·총 입고·총 사용·폐기/회수 (보더 카드, 흰 배경 위 경계 필수).
3. **필터 행** — 기간 ▾ · Lot 칩(선택 시 파란 활성 + ✕ 해제) · 이벤트 ▾ / 우측 `이벤트 N건 · 마지막 기록`.
4. **이력 테이블 (본체)** — 열 순서 고정: `일시 | 구분 | 수량 | 잔량 | 상세`. 숫자 우선, 상세는 뒤(truncate).
   - 구분: 아이콘 칩 + 라벨 — 입고(blue ▣)/사용(slate −)/회수·폐기(rose ↩)/알림(amber !, 수량·잔량 은 `—`)
   - 수량: 부호 포함(+10/−4), 입고 blue·회수 rose 강조
   - 잔량: 행 시점 누적. **불일치 행은 잔량만 red + 상세에 문장으로** `잔량 불일치 — 기록 0개, 현재고 1개` (≠·수식 기호 금지, 행 배경 #fef7f7)
   - 상세: 담당자·사용처(시험번호)·Lot(mono)·검수 결과·사유
5. **우측 레일** — ① 불일치 경고 카드(red): 문장 서술 + CTA `불일치 구간 조정 기록 추가` ② 사용량 요약: 월평균 소비·예상 소진·재주문 주기 ③ 연결 문서: CoA(열기)/MSDS(미등록 시 업로드).

## 2. 모바일 (1b)

- 요약 4지표 1행 압축 → 필터 칩 한 줄(가로 스크롤, ⚙ 세부 시트 — 전역 필터 문법) → 카드형 타임라인(truncate, 셀 중간 깨짐 금지).
- 불일치는 타임라인 내 red 카드로 삽입.
- 하단 출력 바(`Excel` + `실사 리포트 PDF`) — bottom-nav·운영 브리핑 FAB와 겹침 금지 (콘텐츠 끝 sticky).

## 3. 상태별 (전부 구현 — 1b ②~⑤)

- **로딩**: 스켈레톤 + shimmer.
- **데이터 없음**: "아직 입고 이력이 없습니다" 사유 명시 + `입고 기록하기` CTA.
- **부분 데이터(수량 추적 모드)**: 상단 blue 안내 "이 품목은 수량 추적 모드입니다. Lot·사용자·사용처는 기록되지 않습니다 — 누락이 아닙니다" + `Lot 추적으로 전환 ›`. 각 행에 `Lot·사용자 미기록 (수량 모드)` 표기 — 빈칸 금지.
- **불일치 경고**: §1-4·§1-5.
- **권한 없음(Basic)**: "Lot 단위 추적은 Pro 기능입니다" + `품목 이력 보기`(Basic 범위) / `Pro 알아보기` — 막다른 에러 금지. **'계보'라는 단어 전면 금지.**

## 4. PDF (1c — 주 출력)

A4 세로. 상단: 문서 타이틀 + 문서번호(TRC-YYMM-NNNN)·출력일·출력자 / 메타 표(품목·추적 모드·조회 조건·수지 요약 `입고 − 사용 − 회수 = 잔량`) / 이력 표(일시·구분·수량·상세·잔량) / **정합 결론 박스**(불일치 시 문장으로 명시 + 첨부 문서 목록) / QC 작성·QA 검토 서명란 / footer 페이지 번호. 흑백 인쇄 안전(색 의존 금지).

## 5. 모션 (2a — 전부 기능적, reduced-motion 폴백 필수)

- 행 stagger 등장: `trcRow` fade+8px, .45s ease, 행당 delay 40~50ms (최대 ~15행까지만, 이후 즉시)
- 요약 지표·잔량 카운트업: 0.9s cubic ease-out, 필터 변경 시 재실행
- 불일치 카드 1회 펄스: scale 1.02, .6s, **1회 후 정지** (반복 금지)
- 스켈레톤 shimmer / PDF 버튼 `생성 중…` 진행 상태 → 완료 체크
- 금지: 반복 애니메이션·패럴랙스·바운스. `@media (prefers-reduced-motion: reduce)` 전부 무효화.

## 6. 데이터 계약

```ts
HistoryEvent = {
  at: ISODateTime,
  type: 'IN'|'USE'|'RETURN'|'ALERT',
  qty: number|null,            // ALERT는 null
  balanceAfter: number|null,   // 서버 산출 누적 잔량
  lotNo: string|null,          // 수량 모드면 null
  actor: string|null, destination: string|null,
  detail: { vendor?, expiry?, inspection?: 'PASS'|'REJECT', reason?, disposal?: 'RETURN'|'DISPOSE', resolvedAt? },
}
Summary = { current, totalIn, totalOut, totalDisposed, mismatch: { recorded, actual } | null }
```
- 잔량·불일치는 **서버 산출** (클라 재계산 금지 — canonical truth).
- 추적 모드: `QUANTITY` | `LOT`. Basic 플랜 = 품목 단위, Pro = Lot 단위 + PDF 리포트.
