## 1. 헤더 2단 (1a) — `IntroNavbar` 재작성

- IntroNavbar를 MainHeader 대체가 아니라 **아래 붙는 서브바**로: `top: 3.5rem`(h-14), MainHeader는 항상 노출.
- MainHeader 모바일(비로그인)에 **로그인 아웃라인 버튼 상시 노출**: 햄버거 왼쪽, `h-8 px-3 border border-slate-500/45 rounded-lg text-slate-200 text-xs font-bold`. (여유 되면 `무료로 시작하기` 채색 버튼도 — 좁으면 로그인만.)
- 앵커 탭: 가로 스크롤 유지, active 인디케이터(`layoutId`) 유지. `cta` 탭 라벨은 `시작하기` 유지.
- 스크롤 다운 시 MainHeader만 접히고 서브바 유지(선택 고도화) — 최소 요건은 "로고·로그인이 가려지지 않음".

## 2. 연결 포인트 압축 (1a) — intro/page.tsx `#connection`

- **막대(pct)와 "(막대는 연결 강도 예시)" 문구 삭제.**
- 카드 5개 그리드 → **스텝 리스트 1카드**: 흰 카드 안에 행 5개(아이콘 칩 34px + 제목 + 보조설명 11.5px + ↓ 커넥터, 행 구분선 `#EEF2F7`). 데스크톱도 동일 카드(max-w-xl 중앙) 또는 2열.
- 보조설명 예: 검색→후보 정리 "결과에서 후보를 바로 저장" / 비교→선택안 확정 "조건 나란히 비교 후 확정" / 요청 생성 "선택안 기준 요청안 자동 초안" / 발주 준비→입고·재고 "결정 기록이 운영으로 연결" (입고 반영→Lot 기록은 마지막 행에 흡수).

## 3. 역할별 변화 (1b) — intro/page.tsx `#roles`

- 모바일(<md): 카드 3개 세로 나열 → **역할 탭 3개(연구·QC/구매/운영 관리) + 카드 1장 + 페이지 도트**(스와이프 전환).
- 카드 내부 이전/이후 재질 대비:
  - 이전 = `#E9EDF3` 배경 + `1px dashed #CBD5E1` + `BEFORE · 이전` 흰 pill + 본문 `#64748B` + 문제 칩(탭 5개·엑셀 수기 취합 등)
  - 커넥터 = 세로 그라디언트 라인(#CBD5E1→#2563EB) + 파란 원형 ↓
  - 이후 = `#0F172A` 다크 카드 + `AFTER · LabAxis` 파란 pill + 본문 흰색 700 + ✓ 효과 칩 2개(green/blue 반투명)
- 데스크톱(md+)은 기존 3분할 유지하되 이전 칸에 dashed 보더, 이후 칸에 파란 좌보더 등 최소 대비 추가(선택).

## 4. 플로팅 CTA 바 — mobile-floating-cta.tsx

- 문의 버튼: `text-slate-300` → **`text-slate-700`(라이트 바 기준) + border 1.5px `#CBD5E1`**. 현재 rounded-md/rounded-xl 혼재 → 11px 통일.
- **스크롤 방향 반응**: 아래로 스크롤 시 `translateY(100%)` 숨김, 위로 스크롤 시 표시(기존 유사 패턴 있으면 재사용).
- `#cta` 섹션 가시 범위에서는 자동 숨김(IntersectionObserver) — 클로징 CTA와 중복 제거.
- `pb-20 md:pb-0`(main-layout)은 유지.

## 5. CTA 문구·목적지 통일

- 전 지점 **`무료로 시작하기`**로 통일: 히어로(제품 시작하기→변경), 플로팅 바(시작하기→변경), 시트(유지).
- 목적지는 §11.267 계열 결정 따름 — **/search 통일 권장**(시트·데스크톱 헤더가 이미 /search). 히어로 `/auth/signin` 직진과 플로팅 바 `/auth/signin?callbackUrl=/search`를 /search로 정합할지는 §11.267c(가입 의사 직진) 결정과 충돌하므로 **착수 전 1건 확인 필요**.
- 클로징 CTA `요금 & 플랜 보기`는 목적이 다르므로(가격) 유지 가능하되, 주 버튼을 `무료로 시작하기`+보조 `요금 & 플랜`으로 바꾸는 안 권장.
- 재방문 사용자(로그인 이력 쿠키) 감지 시 헤더 주 버튼을 `로그인`으로 치환(선택 고도화).

## 6. 데이터 차트 — intro/page.tsx `#data`

- 막대색: `i>=6 ? '#3B82F6' : '#93C5FD'` (기존 #DBEAFE 소실 수정).
- 영문 섹션 라벨(Research & Procurement / Organization / Data Visualization)은 모바일에서 숨김(`hidden md:flex`) 또는 전면 삭제.

## 7. 메뉴 시트 — main-header.tsx (비로그인)

- 로그인 행(회색 텍스트) → 하단 CTA 영역에서 **아웃라인 버튼 + 파란 `무료로 시작하기` 2버튼 나란히**(1c 참조): `flex gap-2`, 로그인 `flex-1 h-11 border border-slate-500/45 rounded-xl text-slate-200 font-bold`.
- 나머지(nav 3행, ESC/딤 닫기, mobileMenuIn 애니메이션) 유지.

## 9. 도입·문의(/support) — 히어로가 헤더에 먹힘

- **원인 실측:** `support/page.tsx`의 `.cp-hero` 내부 패딩이 `py-14 md:py-20`뿐 — `MainHeader`가 `fixed h-14`(56px)인데 상단 오프셋이 없어 eyebrow `도입 및 문의 · Contact`가 헤더 그림자에 붙거나 스크롤 시 겹침. (intro는 `pt-32 md:pt-44`로 회피 중.)
- **수정:** 히어로 컨테이너 패딩을 `pt-28 md:pt-32`(pb는 유지)로 — 또는 `.cp-hero`에 `padding-top: 3.5rem` 오프셋 추가. 기준: eyebrow 위 여백 ≥ 40px.
- **메뉴 시트 통일:** /support의 시트는 별도 구현이 아니라 **같은 `MainHeader` 공용 컴포넌트** — §7(로그인 아웃라인 버튼 승격 + 무료로 시작하기 나란히)을 main-header.tsx에서 고치면 /intro·/support·/pricing 전 페이지에 자동 반영. 페이지별 개별 수정 금지.
- 사이드바 `lg:sticky lg:top-[86px]`는 헤더 h-14 기준 정상 — 변경 불필요.
