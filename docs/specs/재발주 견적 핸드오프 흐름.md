## 1a. 재고관리 KPI — 레드 카드 제거

- KPI 3장(전체 품목/안전재고 미달/만료 임박) 전부 **동일한 흰 카드** (border #e2e8f0).
- 미달 카드는 숫자 `#b91c1c` + 6px 레드 점만 — 보더·배경 채색 금지.
- 강조는 아래 재발주 권장 배너(블루 #eff6ff/#bfdbfe) 하나로 일원화.

## 1b. 재발주 시트 — CTA 정직화 (공급사 없음 분기)

품목에 등록 공급사 0일 때:
- yellow 안내(#fffbeb/#fde68a/#92400e): `이 품목에 등록된 공급사가 없습니다` + "초안을 만든 뒤 바로 공급사 지정 화면으로 이동합니다."
- 주 CTA 라벨: `견적 요청 초안 만들기` → **`초안 만들고 공급사 지정 →`** (다음 화면 예고).
- **`바로 발주` 그린 버튼 숨김** (dead button 제거) — 하단 안내 1줄 `바로 발주는 공급사·단가 확정 후 가능합니다`로 대체.
- 보조: `공급사 소싱에서 먼저 찾기`.
- 공급사 등록돼 있으면 기존 2버튼(견적 요청/바로 발주) 유지.

## 1c. 도착 화면 — 초안 발송 준비 딥링크 (핵심)

- 초안 생성 완료 시 **견적관리 리스트가 아니라 해당 초안의 발송 준비 화면으로 라우팅** (`/quotes/{rfqId}/prepare` 등).
- 헤더: `견적 요청 발송 준비` + RFQ 번호(mono) + `방금 재고관리에서 생성됨`.
- 3스텝 pill: `✓ 품목 확정`(그린) → `② 공급사 지정`(블루 활성) → `③ 발송`(회색).
- 품목 카드: 품목×수량 + `재고관리에서 연동` 배지 + 근거(현재/안전) — **2초 블루 하이라이트 페이드**(`방금 생성` 표시, animation 1회).
- 공급사 지정 패널(블루 보더 활성): 검색 input + `소싱에서 찾기` / `이메일로 추가` + **이전 거래 공급사 추천 1줄**(품목 카테고리 매칭) + `지정` 버튼.
- 하단 CTA: 지정 전 **disabled + 사유 라벨** `발송 검토로 — 공급사 지정 필요`. 지정 시 활성 → 기존 발송 검토 모달로 연속 (재고↔견적 왕복 없음).
- 이탈 안전: `나중에 하기 — 발송 대기로 저장` 텍스트 링크.

## 1d. 견적관리 리스트 — 나중에 저장된 초안 카드

- 상태 pill: ~~`공급사 미정`~~ → **`공급사 지정 필요`** (#fffbeb/#fde68a/#b45309) — 막다른 표현 대신 할 일 표현.
- 카드: RFQ 번호(IBM Plex Mono) + 품목×수량 + `재고관리 재발주안에서 생성 · 2026. 8. 1.` (**연도 포함 표기 통일**).
- CTA 1개: `공급사 지정하고 발송 →` → 1c 화면 복귀.
- 이 상태에선 `예상 금액: 견적 대기` 행 숨김 (정보 0 행 제거).
- 리스트 진입 직후 해당 카드 2초 블루 하이라이트.

## 타이포 토큰

- RFQ·Lot 등 코드 = IBM Plex Mono 500/600. 전역 `font-variant-numeric: tabular-nums`(input·button 포함).
