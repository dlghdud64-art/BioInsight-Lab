## 0. 현행 문제 (2026-08-02 실기기 확인)

L430 탭 행이 `overflow-x-auto scrollbar-hide` 한 행에 **뷰 전환 탭 3개 + "AI 리포트 예시" + "AI 리포트 생성" 버튼 5개**를 담음:
1. 모바일에서 CTA 2개가 화면 밖 — 스크롤바 숨김이라 존재 인지 불가.
2. `ml-auto`(AI 리포트 예시)는 overflow 컨테이너 안에서 무효 — 콘텐츠 폭 > 컨테이너면 정렬 효과 0.
3. `AI 리포트 생성` disabled 사유가 `title` 툴팁뿐 — 모바일에서 안 보임.
4. **dead branch** — `activeTab === "team"` 렌더(L692 위)가 있으나 tabs 배열(L405)에 team 없음 → 진입 경로 0.

## 1. 모바일 (<sm) — 1b

- **탭 = 밑줄(underline) 스타일**로 교체 (칩 스타일 폐기 — 필터로 오인됨):
  - 행: `flex gap-22px, border-bottom 1px #e2e8f0`
  - 선택: 13.5px/700 `#0f172a` + 밑줄 2.5px `#2563eb` (margin-bottom −1px)
  - 비선택: 13.5px/500 `#64748b`
  - 데이터 없는 탭(이상 지출 감지, 3개월 미만): `#94a3b8` 연회색 — 클릭은 허용하되 탭 내부에 빈 상태 안내.
- **AI 리포트 버튼 2개 = 탭 아래 별도 행**, 2열 그리드 `gap 8px`, 높이 42px 통일:
  - AI 리포트 예시: 흰 배경 + `#e2e8f0` 보더, `#475569`
  - AI 리포트 생성 (disabled): `#e2e8f0` 배경 `#94a3b8` — 비활성 사유는 **그리드 아래 인라인 1줄** 우측 정렬 11px `#94a3b8`: `AI 리포트 생성 · 완료된 발주 1건 이상 필요` (title 툴팁 대체).
- 우측 페이드 힌트(`§mobile-budgets §3` span) 제거 — 스크롤 자체가 사라짐.

## 2. 데스크톱 (sm+) — 1c

- AI 리포트 버튼 2개는 **페이지 헤더 우측**(제목·설명 옆 `justify-between`)으로 이동 — 원래 `ml-auto` 의도의 정상 구현.
- 탭 행은 뷰 전환 전용. **`팀별 보기` 탭을 tabs 배열에 추가** (dead branch 해소):
  `{ id: "team", label: "팀별 보기" }` — TeamAnalyticsView 렌더는 이미 존재.
- 탭 스타일은 모바일과 동일 밑줄형 통일 (기존 칩형 폐기 여부는 전역 필터 b안 트랙과 정합 — 이 페이지는 밑줄형 적용).

## 3. 접근성

- 탭: `role="tab"` + `aria-selected`, 버튼: disabled 시 `aria-disabled` + 사유 텍스트를 `aria-describedby`로 연결.
- 히트 영역 44px 유지 (`touch-manipulation` 기존 유지).
