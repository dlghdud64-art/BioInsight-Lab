## 0. 현행 문제 (2026-08-04 실기기 확인)

1. **다크 카드 혼합** — 앱 전역 라이트인데 상세만 운영 브리핑·차단 리스트·KPI·문서 현황 전부 다크. 다크 위 채색 텍스트로 가독성 최악.
2. **동일 정보 3중 중복** — 검수 미완료·문서 누락이 브리핑 바 + 차단/검토/주의 리스트 + 우측 판단 패널에 반복.
3. **목록 우측 패널** — 본문이 "문서 확보" 체크 하나뿐, 차단 사유 없이 그린 `재고 반영` CTA가 활성처럼 보임.
4. **헤더 불일치** — 입고 관리만 타이틀이 박스형. 재고 관리 등은 플레인 타이틀.
5. **처리 동선** — 라인별 처리를 매번 상세에 들어와 개별로 해야 함.

## 1. 상세 페이지 (1a) — 라이트 전면 재구성

- **테마**: 전 카드 흰 배경 + `#e2e8f0` 보더. 다크 카드 0.
- **헤더**: 플레인 타이틀 문법 통일 — 브레드크럼(RCV 번호 mono) → 타이틀 22px/800 + 상태 pill → 메타 1줄(공급사 · PO 링크 · 도착일 · 담당). 우측 `← 목록으로`.
- **4단계 스텝퍼**: 입고(✓그린) → 검수·문서(블루 활성 + "진행 중" pill) → Lot 등록 → 재고 반영.
- **KPI 3열**: 수령 23/25 · 검수 1/3 합격 · 문서 2/3 첨부 — 게이지 바(정상 블루/주의 앰버) + 보조 1줄.
- **수령 라인 리스트**: 상태 pill(합격/검수 대기/보류) + 품목 + 사유 1줄 + 인라인 해소 액션(COA 첨부 / 보류 검사 판정). 합격 라인엔 Lot mono 칩 + `COA 인식` 배지 + 유효기간.

## 2. 우측 "다음 조치" 패널 — 3중 중복 통합 (핵심)

브리핑 바·차단 리스트·판단 패널을 **단일 패널**로:
- 번호 붙은 조치 리스트(색 = 심각도): ① COA 확보(확인 필요) ② 보류 검사 판정.
- 하단 CTA 단일화: **`남은 N건 처리하고 반영`** (블루 활성) → 일괄 처리 모달(§4) 진입. 부분 반영·disabled 재고 반영 버튼 없음.
- **문서 카드**: 거래명세서/COA 목록. 미첨부 COA엔 `직접 첨부`(기본) + `공급사 요청`(보조) — COA는 대부분 배송 동봉이므로 리마인더 독촉 흐름 없음. 안내 1줄: "COA 업로드 시 Lot·유효기간 자동 인식 → 라인에 채움 (확인 후 확정)".
- **반영 이력 카드**: 반영 시 날짜·내용·재고 LOT 링크 + 잔여 라인 상태 1줄.

## 3. 목록 우측 패널 (1b)

- 헤더: rb-id(mono) + 상태 pill + ✕.
- **미니 스텝퍼**(✓입고 ✓검수 ✓문서 ④반영) + 요약 3행(상태/담당/기한 — 기한 임박 레드).
- **차단 사유 카드**(yellow): "반영 전 1건 남음 · 보류 라인 검사 판정 필요".
- CTA 2개: `상세 열기`(아웃라인) + **`남은 1건 처리`**(블루 활성) → 상세 진입 없이 일괄 처리 모달 직행. 안내 1줄: "처리 모달에서 판정 완료 시 바로 재고 반영".

## 4. 일괄 처리 모달 (1d) — 원버튼 해소 (신규 핵심)

목록/상세 어디서든 원버튼 진입. 상세 페이지 왕복 없이 남은 조치를 한 모달에서 순차 처리:
- 헤더: `남은 조치 처리 1/2` + 진행률 바.
- 스텝 = 미해소 조치 1개씩 (활성 스텝만 펼침, 다음 스텝은 dim 요약행):
  - 문서 스텝: 드래그앤드롭 COA 업로드(자동 인식 안내) + "파일이 없습니다, 공급사에 요청" 보조 버튼(해당 스텝을 '외부 대기'로 넘김).
  - 보류 스텝: 합격/폐기 판정 + 사유 메모 필수.
- 하단: `나중에`(처리분 저장 후 이탈) + `다음`(현재 스텝 미완료 시 disabled + 사유 라벨).
- **마지막 스텝 완료 시 재고 반영까지 자동** — 별도 반영 버튼 불필요. 외부 대기 스텝이 남으면 반영 보류 + 상태 유지.

## 5. 모바일웹 (1c)

- 단일 컬럼. **다음 조치 패널 최상단**(액션 인라인) → KPI 3열 컴팩트 → 라인 접힌 카드 스택(탭 → 상세) → 하단 CTA.
- CTA: **`남은 2건 처리하고 반영`** 단일 버튼(sticky) → 일괄 처리 모달(바텀 시트로 렌더).
- 미니 스텝퍼 1줄(10.5px).

## 6. 배선 규칙

- 일괄 처리 모달 완료 → 재고 Lot 생성 + 반영 이력 기록(이중 반영 금지 — 검수 핸드오프 §5와 동일 파이프라인). 중간 이탈 시 처리분 저장(front-only 금지).
- COA 첨부 → OCR 자동 인식(Lot·유효기간) → 파란 배경 + `COA 인식` 배지, 담당자 확인 후 확정(자동 확정 금지).
- 모달 `다음` disabled 사유는 항상 버튼 라벨에 인라인(툴팁 금지).
- em dash(—) 사용 금지, 쉼표/가운뎃점으로.
