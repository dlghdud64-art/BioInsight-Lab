# 모바일 예산 관리 · 지출 분석 개선 — 구현 지시문 (핸드오프)

**제품:** LabAxis 모바일 웹 (`/dashboard/budgets`, `/dashboard/spend-analysis`, viewport < 768px)
**프로토타입:** `모바일 대시보드 개선.dc.html` — 7a(예산 관리) · 7b(예산 등록 시트) · 8a(지출 분석)

---

## 1. 예산 관리 (7a)

- **헤더 압축** — 3줄 설명 → 한 줄("등록 · 집행 · 승인 대기 · 초과 위험을 한곳에서"). 보고서 내보내기는 아이콘, `＋ 예산 등록`만 버튼.
- **온보딩 배너(중형)** — 예산 0개일 때 헤더 바로 아래: 라벨(`예산 통제 시작하기 · 2분`) + 제목 15px + 설명 1줄 + CTA `첫 분기 예산 설정 ›` / `나중에`. 잘림 금지.
- **0건 KPI 나열 금지** — 즉시 확인·차단 위험·승인 대기가 전부 0이면 가로 스크롤 카드 3장 대신 **초록 한 줄 요약**("예산 상태 정상 · 0/0/0" + `상세 ›`). **1건 이상이면 해당 항목만 카드로 승격.**
- **거대 점선 빈 박스 금지** — 접힌 행 2개(카테고리별 지출 · 예산 풀별 소진율), 데이터 생기면 제자리 확장(구매 리포트와 동일 규칙).

## 2. 예산 등록 시트 (7b)

**진입점 3곳 → 시트 하나:** 예산 관리 헤더 `＋ 예산 등록` / 7a 배너 CTA / 지출 분석 8a 단계 카드 `등록 ›`.

- 구성: 풀 이름 → 분기 한도(풀폭, 우측 정렬 ₩) → **적용 기간 = 분기 세그먼트**(2/3/4분기 + 아래 실제 날짜 확인 표기) → 경고 임계 구간 시각화(정상 ~70% / 경고 70–90% / 차단 90%+) → 초과 발주 사전 차단 토글 → 연동 안내 → CTA `예산 풀 등록`.
- **등록 즉시:** ① 예산 관리 — 온보딩 배너 dismiss, 상태 요약 실계산 전환 ② 지출 분석 — 활성화 2/3, 남은 단계(첫 발주)만 CTA. 임계값은 두 화면 경고·차단의 **단일 소스**.

## 3. 지출 분석 (8a)

- **히어로+활성화 단계 중복 통합** — 같은 말 반복하던 배너와 체크리스트 카드를 한 카드로: 라벨에 진행(`분석 활성화 · 1/3 완료`) + 진행 점 + 내부 단계 3줄(완료 취소선 / 현재 강조+CTA / 다음 예고).
- **CTA 하나만** — 대형 초록+다크 버튼 2개 제거. 현재 단계(예산 등록)에만 `등록 ›`. 초록 대형 CTA 금지(초록은 완료 표시만).
- **탭 스크롤 힌트** — 칩 잘림 우측에 배경색 페이드.
- **분석 미리보기** — 소진율·의존도·이상 감지 접힌 행 3개, 데이터 시 제자리 확장.

## 4. 웹 ↔ 모바일 기능 패리티

| 웹 기능 | 모바일 대응 | 상태 |
|---|---|---|
| 보고서 내보내기 | 헤더 다운로드 아이콘 | ✓ 유지 |
| 예산 등록 | 헤더 버튼 + 7b 시트 | ✓ 유지 |
| KPI 3종 (즉시 확인/차단 위험/승인 대기) | 0건=한 줄 요약, 1건+=카드 승격, `상세 ›` 전체 | ✓ 요약 표현만 변경 |
| 카테고리별 지출 | 접힌 행 → 제자리 확장 | ✓ 유지 |
| 예산 통제 온보딩 | 중형 배너 + 7b | ✓ 유지 |
| 임계 구간·차단 설정 | 7b 시트 (웹과 동일 값) | ✓ 단일 소스 |
| 지출 분석 탭 4종 | 칩 + 페이드 힌트 | ✓ 유지 |
| 활성화 단계 체크리스트 | 배너에 통합(단계 3줄) | ✓ 통합 |

> 원칙: 웹 기능 삭제 없음. 표현만 밀도에 맞춰 접힘/요약되고, 값·설정은 웹과 같은 소스에서 읽고 쓴다.
