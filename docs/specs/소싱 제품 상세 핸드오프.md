# 소싱 제품 상세 — 개선 (핸드오프)

**제품:** LabAxis · 제품 상세 (`/products/:id`)
**프로토타입:** `소싱 제품 상세 개선.dc.html` (1a 본문 · 1b 우측 패널)

---

## 0. 문제

1. **빈 섹션이 화면 절반** — `상세 스펙 없음` · `등록된 SDS 없음` · `연관 추천 분석 중…`이 각각 큰 카드 점유.
2. **미등록 경고 3중 분산** — 상단 완성도 25%(미등록 6개) / MSDS·SDS 미등록 배너 / `위험도: 미분류·MSDS 없음` 칩.
3. **우측 CTA 중복** — 담김 칩 2개 + 파란 `견적함에 담김` 대형 버튼 + `비교 추가`. 이미 담긴 상태인데 담기 버튼이 주 CTA.
4. **규제 포털 6버튼 동급 나열**, 대체품 추천이 **최하단**.

## 1. 본문 (1a)

- **미등록 체크리스트 1개로 통합** — 상단 yellow 카드(`#fffbeb/#fde68a/#92400e`): 진행 바 + 6개 항목 2열, 항목별 액션(정보 요청 / 업로드 / 스펙 편집 / 안전 정보 편집). 하위 중복 배너 **삭제**.
- **데이터 0건 섹션은 접힌 한 줄** — `▸ 상세 스펙 · 미등록 · [정보 요청]`, `▸ 등록된 SDS 문서 · 0건 · [SDS 업로드]`. 값이 있는 섹션만 펼침.
- **규제 포털** — 상시 2개(식약처 포털·화학물질안전원) + `더보기`, 카드 대신 텍스트 링크 행.
- **대체품 추천을 안전·규제 위로 이동** — 카드에 대비 배지(`가격 공개`, `SDS 있음`) 표기. 정보 미등록 품목일수록 먼저 노출.
- **"분석 중…"** — 스켈레톤 카드 대신 접힘 유지, 결과 도착 시 자동 펼침.

## 2. 우측 패널 (1b)

- 담긴 상태: 칩 한 줄 `✓ 견적함·비교함에 담김 [해제]`(green `#f0fdf4/#dcfce7/#15803d`)로 강등.
- **주 CTA = `견적 요청서 만들기 →`** (green `#16a34a`) — 하단 바와 같은 목적지.
- 담기지 않은 상태에서만 파란 `견적함에 담기`가 주 CTA.
- 보조: `비교 검토` · `재고 조회` 2분할 아웃라인.
- `맞춤 견적 문의` 다크 카드는 주 CTA와 경쟁 → **푸터 텍스트 링크로 강등**.
- 가격 영역: `견적 후 확정` + 1줄 설명(납기·최소 주문 포함) — 3행 반복 테이블 축약.

## 3. 검색 결과 화면 연계

- 헤더 카운터 중복(`비교 후보 2 / 견적 후보 3`)은 `소싱 카운터·타이밍 핸드오프.md` §1 규칙 동일 적용(헤더에서 삭제, 하단 바 단일 소스).

## 4. QA

- [ ] 미등록 경고가 상단 체크리스트 1개로만 존재
- [ ] 0건 섹션이 접힌 한 줄 + 액션으로 렌더
- [ ] 대체품이 안전·규제 위, 대비 배지 표기
- [ ] 담김 상태에서 주 CTA가 `견적 요청서 만들기`
- [ ] 해제 클릭 시 서버 반영 후 상태 변경(front-only success 금지)
- [ ] 규제 포털 2 + 더보기
- [ ] 다크 문의 카드 제거·강등
