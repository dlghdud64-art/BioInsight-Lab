# 모바일 견적 관리 개선 — 구현 지시문 (핸드오프)

**제품:** LabAxis · 견적 관리 모바일 웹 (`/dashboard/quotes`, viewport < 768px)
**범위:** 견적 관리 화면(우선 추천 배너·리스트) + 리마인더 모달 + 공급사 발송 검토 시트
**프로토타입:** `모바일 대시보드 개선.dc.html` — 3a(화면) · 4a(리마인더) · 5a(발송 검토)

---

## 1. 견적 관리 화면 (3a)

### 우선 추천 배너
- **"회신 독려" 표현 금지.** 카피: 품목명 1줄 + 액션 문장 1줄 분리.
  - 예: `Sigma-Tech PBS 1X (Sterile)` / `공급사 회신을 확인할 차례예요`
- 대시(`—`) 연결 문장 금지. 메타는 한 줄: `RFQ-2606-A698 · 마감 D-2 · 공급사 1곳` (배너 라벨의 "회신 추적" 중복 표기 제거).
- CTA: `🔔 리마인더`(흰 배경) + `나중에`(아웃라인).

### 날짜 칩
- "7월 3주" 대신 **오늘 날짜만**: `7.20 (월)`. 마감 D-day는 KPI·배너 메타에 이미 있으므로 중복 금지.

### 리스트 카드
- **왼쪽 세로 색 띠 제거** — 상태는 상단 pill로만.
- 카드 구성: 상태 pill + 우선도(우측) → RFQ 코드 → 품목명 → 하단(상태 정보 + 상황별 CTA).
- 빈 값 표시(`⏱ —`) 금지 → 상황별 CTA로 대체:
  - 공급사 미정 → 앰버 칩 `공급사 미정` + CTA `공급사 추가 ›`
  - 준비된 건 → `공급사 N곳 · 마감 D-N` + CTA `발송 ›`
- **RFQ 코드에 모노스페이스 금지** — 본문 폰트(Pretendard) 세미볼드 + 자간 `.03em`. 영문·코드가 한글과 동떨어져 보이는 원인.

## 2. 리마인더 모달 (4a) — 회신 추적 건

바텀 시트(그랩바 포함):
1. 헤더: 🔔 회신 리마인더 / "아직 회신하지 않은 공급사에게 보냅니다"
2. 케이스 요약: 품목명 + RFQ·마감 D-day + 상태 pill(회신 추적)
3. **받는 공급사 · 미회신 N곳** — 공급사 행(이니셜·회신 0/1·요청 후 경과일) + `D+N` 경과 배지(앰버)
4. 전달 메시지 · 자동 생성(+수정): 회신 요청 문구 — **"독려/독촉" 단어 금지**
5. 재응답 기한(일 입력)
6. "발송 내역은 활동 로그에 기록됩니다" + 앰버 CTA `🔔 리마인더 발송`

규칙: 대상은 **미회신 공급사만** 자동 필터. 회신 완료 공급사 제외.

## 3. 공급사 발송 검토 시트 (5a)

현행 문제 → 수정:
1. **스텝퍼 정합** — 1단계(공급사 선택)가 막혔는데 3단계(메시지 검토)에 초록 체크가 뜨는 모순 제거. 막힌 단계만 앰버 `!`, 이후 단계는 회색 대기. 완료 체크는 실제 완료에만.
2. **경고 통합** — 상단 노랑("공급사를 먼저 추가하세요") + 하단 빨강("연락처 필요") 중복 제거 → **공급사 추가 히어로**(파란 테두리) 하나만: 이메일 입력 + 공급사명(선택) + `추가` + `✦ LabAxis 추천 공급사 탐색`.
3. **접기 구조** — 전달 메시지·응답 기한은 기본 접힘(제목 + 요약 줄 + `펼치기`/`변경`). 긴 스크롤 제거.
4. **푸터 세로 위계** —
   - `공급사 추가 후 전송 가능 · 0곳` (비활성 CTA, **사유 인라인**) → 1곳+ 추가 시 `N곳에 요청 전달`로 활성
   - `✉ 요청서 다운로드 · 직접 전달용` (아웃라인 풀폭) — **플랫폼 밖 수동 전달용 폴백**, 공급사 0곳 상태에서만 노출 권장
   - `취소` (하단 중앙 텍스트)
5. 케이스 칩: 담당자 대신 **RFQ + 품목명** 노출.

## 5. QA 체크리스트

- [ ] "회신 독려/독촉" 문구가 어디에도 없다
- [ ] 배너가 품목 1줄 + 액션 1줄, 대시 없음
- [ ] 날짜 칩 = 오늘 날짜만(마감 중복 없음)
- [ ] 리스트 카드에 왼쪽 색 띠·빈 `⏱ —` 없음, 상황별 CTA
- [ ] RFQ 코드가 본문 폰트로 렌더(모노 아님)
- [ ] 리마인더 대상 = 미회신 공급사만, D+N 경과 배지
- [ ] 스텝퍼에 가짜 체크 없음(막힌 단계 앰버, 이후 대기)
- [ ] 경고 1개(히어로)만 존재
- [ ] 메시지·기한 기본 접힘
- [ ] 전송 버튼에 비활성 사유 인라인, 다운로드는 "직접 전달용" 라벨
- [ ] 터치 타겟 44px 이상
