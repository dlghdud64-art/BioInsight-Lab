# 모바일 활동 로그 · 전역 드롭다운 개선 — 구현 지시문 (핸드오프)

**제품:** LabAxis · 활동 로그/감사 추적 모바일 웹 (`/logs`, viewport < 768px) + 전역 메뉴 컴포넌트
**범위:** 라우팅 정합 · 활동 로그 필터 · 로그 리스트 · 전역 드롭다운/메뉴 스타일
**프로토타입:** `모바일 활동 로그 개선.dc.html` — 1a(화면) · 1b(세부 필터 시트) · 1c(더보기 메뉴) · 2a~2c(드롭다운 스타일)

---

## 0. 진단

1. **라우팅 버그** — 더보기의 "활동 로그"를 눌러도 감사 추적으로 진입. 메뉴 하이라이트도 실제 경로와 불일치.
2. **이중 노출** — 활동 로그·감사 추적이 더보기 메뉴 별개 항목 + 페이지 내 탭으로 중복.
3. **필터** — 11개+ 이벤트 타입 데스크톱 드롭다운이 화면을 덮고, 두 번째 필터("전체")는 무엇의 전체인지 불명.
4. **드롭다운 스타일(전역)** — 패널이 연회색 채색 배경 + 그림자 없음 → 레이어 깊이감 없음. 항목 ~52px 데스크톱 밀도, 선택 상태 표기 모호.

## 1. 라우팅 · 메뉴 (1c)

- 더보기 메뉴 항목은 **활동 로그 하나만**: `/logs?tab=activity` 진입. 감사 추적은 페이지 내 탭(`?tab=audit`), **관리자 권한일 때만 탭 노출**.
- 페이지는 탭 파라미터를 그대로 반영 — **기본 탭 하드코딩 금지**(활동 로그 클릭→감사 추적 진입 버그의 원인).
- 메뉴 하이라이트 = 실제 현재 경로와 일치.

## 2. 활동 로그 화면 (1a)

### 필터 — 한 줄
- 단일 가로 스크롤 행(`overflow-x:auto`, 우측 페이드 힌트): 도메인 칩(전체/견적/리스트/재고/입고) + 구분선 + `기간 · 7일 ▾` + `담당자 ▾` + `⚙ 세부`.
- 11개 이벤트 타입 드롭다운 제거. 세부 타입은 `⚙ 세부` → 바텀 시트.
- 셀렉터 라벨 명시(`기간 · 최근 7일`) — 라벨 없는 "전체" 금지.

### 세부 필터 시트 (1b)
- 시트는 **현재 선택된 도메인의 타입만** 노출(전체 선택 시에만 도메인 그룹 나열). 칩 멀티 선택 + `필터 적용 · N개` CTA.
- 적용 후 목록 위 활성 필터 칩(✕ 개별 해제), `⚙ 세부`에 개수 배지.

### 리스트
- **날짜 그룹 헤더**(오늘/어제/날짜).
- 행: 도메인 이니셜 칩(견/리/재/입… 색상 구분) + `{사용자}님이 {행동}` + 대상 객체 메타(RFQ·품목·시각) + `›`.
- **행 탭 = 대상 객체로 딥링크**(견적 상세, RCV 등). 눌리지 않는 행 금지.

## 3. 전역 드롭다운/메뉴 스타일 (2a~2c)

### 토큰 (전 화면 공통 — bg-popover 흰색으로 통일)
| 항목 | 값 |
|---|---|
| 패널 | `#fff` · 보더 `#e6eaf0` · radius 12 · 그림자 `0 12px 32px rgba(15,23,42,.14)` |
| 항목 | 높이 44px · radius 8 · 흰 배경 |
| 선택 항목 | `#eff6ff` 배경 + `#1d4ed8` 텍스트 + ✓ (선택만) |
| 금지 | 회색 채색 패널(`#f1f5f9`류), 내부 스크롤, 첫 항목만 체크 |

### 사용 규칙
- **단일 선택 + 항목 ≤7개** → 드롭다운. 내부 스크롤 금지.
- **8개 이상 또는 멀티 선택** → 바텀 시트(그룹 헤더 + 칩 + 적용 CTA).
- 모든 항목에 선택 상태 표기. 바깥 탭으로 닫힘(dim 없음).
