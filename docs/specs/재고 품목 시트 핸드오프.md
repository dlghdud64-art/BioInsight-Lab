## 0. 현행 문제 (2026-08-04 실기기 확인)

1. 값 없는 필드도 전부 행 렌더 — 상태·보관 조건·공급사·납기·용도 5개가 대시(‑). 시트 절반이 빈 정보, 세로 2화면 분량.
2. 섹션 카드 4개(LOT/위치/구매 연결/안전 정보)가 각각 제목 + 2열 그리드 — 밀도 낮음.
3. 핵심 경고(안전재고 미달)와 유일한 CTA(AI 재발주 검토)가 최하단 — 스크롤해야 발견.
4. "자동 재주문 비활성화"가 안전 정보 카드에 — 재발주 맥락과 분리.

## 1. 시트 재구성 (1a) — 스크롤 없이 한 화면

위에서부터:
1. **헤더**: 품목명 19px/800 + 상태 pill(부족 앰버) + 메타 1줄(제조사 · Cat mono · Lot mono) + ✕.
2. **경고 + CTA 카드** (yellow #fffbeb/#fde68a): `안전재고 미달 · 현재 1개 / 안전 10개` + 게이지 바 + 풀폭 블루 CTA **`AI 재발주 검토 · 권장 N개`** (권장 = max(0, safety − qty)).
3. **핵심 3수치 그리드**: 수량(1/10, 미달 앰버) · 유효기간 · 보관 위치(미지정 = 앰버 표기).
4. **채워진 필드만** 컴팩트 행 리스트 (라벨 좌 / 값 우): 최소 주문 · 위험물 · 자동 재주문.
5. **미입력 접기 1줄**: `미입력 4건 · 공급사, 납기, 용도, 보관 조건` + `채우기` 버튼.
6. **액션 2버튼**: `QR 스캔 · 입출고` (아이콘 포함, 강조) + `상세 보기`. 캡션 1줄: "스캔 후 입고/출고 자동 판별 · 수동 입출고는 상세 보기에서".

## 2. 빈 필드 표기 규칙 (전역)

- 대시(—/ㅡ) 노출 금지.
- **운영상 의미 있는 공백**(보관 위치, COA 등): `미지정`/`없음` 정직 표기(앰버) + 채우기 액션.
- **단순 미입력**(용도, 납기, 공급사, 보관 조건): 행 숨김 → "미입력 N건" 접기 1줄로 묶음.

## 3. 액션 목적지 (QR 우선 운영)

- **QR 스캔 · 입출고**: 카메라 스캔 직행 → 스캔 후 입고/출고 자동 판별(입고 예정 건 매칭 시 입고, 아니면 출고 수량 스테퍼 시트). 모바일 앱(RN)은 네이티브 스캐너, 모바일웹은 getUserMedia.
- **상세 보기**: 품목 브리핑 화면(LOT 카드·입출고 이력·권장 액션·수정 이력)으로 이동. **수동 입고/출고는 브리핑 내 폴백 액션으로만** — 라벨 훼손·실사 정정용. 시트 1차 버튼에서 제거.
- 시트 = 요약 + 즉시 액션 / 브리핑 = 전체 맥락. 역할 분리.
